TaskBoard Pro: Project Overview
TaskBoard Pro is a high-performance, portfolio-ready Kanban board designed with a premium, modern aesthetic.
Instead of a standard, utilitarian dashboard, TaskBoard Pro features a stunning Glassmorphism UI. It uses a  gradient background paired with frosted-glass translucent columns, and smooth interactive hover effects.
Tech Stack
Built for speed and fluid interactions using:
Next.js 15+ for the core framework
Tailwind CSS for the styling and glass effects
dnd-kit for seamless drag-and-drop physics
Core Features
Interactive Pipeline: Four main columns to manage workflows: Backlog, In Progress, Review, and Done.
Draggable Task Cards: Cards feature titles, descriptions, and color-coded priority tags (Red for High, Amber for Medium, Blue for Low).
Fluid Drag & Drop: Smooth animations when picking up and moving tasks across the board.
Add Task Modal: A sleek, matching glass-themed modal to easily inject new tasks into the workflow.
